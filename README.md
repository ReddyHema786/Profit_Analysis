# E-commerce Sales & Profit Analysis

## Project Overview

This project analyzes e-commerce sales and profitability across
products, categories, and regions. A Linear Regression model was
developed to predict Profit using Sales and Quantity, and an
interactive Power BI dashboard was created to visualize the
business performance.

## Objective

- Analyze sales and profit performance
- Identify profitable categories and products
- Compare regional profitability
- Analyze the relationship between Sales and Profit
- Predict Profit using Linear Regression
- Build an interactive Power BI dashboard

## Dataset

The dataset contains 3,500 e-commerce transactions with the following
columns:

- Order Date
- Product Name
- Category
- Region
- Quantity
- Sales
- Profit

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Power BI

## Data Analysis

The project includes:

- Data cleaning
- Exploratory Data Analysis
- Category-wise profit analysis
- Region-wise profit analysis
- Product-wise profit analysis
- Correlation analysis
- Sales vs Profit analysis

## Machine Learning

### Algorithm

Linear Regression

### Features

- Quantity
- Sales

### Target

- Profit

### Model Evaluation

The model was evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Power BI Dashboard

The dashboard contains:

- Total Sales
- Total Profit
- Total Quantity
- Average Profit
- Profit by Category
- Profit by Region
- Top Products by Profit
- Sales vs Profit
- Monthly Profit Trend
- Interactive slicers

## Business Insights

- Electronics was the highest-profit category.
- West was the highest-profit region.
- Camera was the highest-profit product.
- Sales and Profit were analyzed using correlation and regression.

## Conclusion

The project demonstrates how Python, machine learning, and Power BI
can be combined to analyze e-commerce performance, predict profit,
and provide data-driven business insights.
